# goit-js-hw-08

Галерея зображень із модальним переглядом на basicLightbox.

## Запуск

Відкрийте index.html через Live Server або інший локальний HTTP-сервер.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save.

Зображення та basicLightbox завантажуються через CDN, тому потрібен інтернет.
